Today we are going to explore how we can use CSS custom properties (variables) to drive complex web layouts.

## The Semantic Power of Tokens

By defining semantic tokens, we can keep our codebase structured:

```css
:root {
  --background: #faf7f4;
  --text-primary: #1c1410;
}
```

This makes it incredibly easy to switch themes on the fly.
