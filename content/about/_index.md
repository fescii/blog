Welcome to my site. I am Fredrick, a systems architect, software engineer, and the co-founder of aduki, Inc. operating out of Kenya. 

This site will serve as a log for my technical research, system designs, and engineering notes. My approach to software development is straightforward: I prefer building core systems from scratch rather than relying on bloated third-party tools or legacy web technologies. My stack is heavily focused on high-performance languages; specifically Rust, Go, and Kotlin, alongside C for lower-level implementations. 

I prioritize pure algorithms and system-level architecture over industry buzzwords. Currently, my time is dedicated to several core projects:

| Project | Description |
|---------|-------------|
| **Platform OS** | Architecting an operating system built around web-like discovery |
| **ATOM Framework** | Developing a custom, multi-timeline transcription format utilizing pure system-level implementation in Rust and C |
| **Vouch** | Building the underlying infrastructure for a trust-based mobility platform |
| **aduki, Inc.** | Scaling our foundational technologies and technical teams |

Expect future posts to be direct, technical, and focused on the realities of building infrastructure from the ground up.
